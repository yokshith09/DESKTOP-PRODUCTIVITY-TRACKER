# Production-readiness audit — 2026-10-28 (first pass)

Scope of this pass: automated checks plus a targeted read of the riskiest surfaces. **It is not a line-by-line review of every module, and nothing here was run on a real PC.** Severity: High = could lose data or blank the app; Medium = wrong or insecure in a plausible case; Low = polish.

## Fixed in this pass
| # | Severity | Finding | Fix |
|---|---|---|---|
| 1 | High | **No error boundary.** One render error in any screen would blank the whole window (main, note and pet windows). | `ErrorBoundary`: calm message with Try again / Reload (data is in the database, untouched); the pet window retries quietly up to three times. 3 tests. |
| 2 | Medium | `pnpm audit --prod`: 5 advisories (1 high, 3 moderate, 1 low) in `vite` 7.3.6 (dev-server file-serving and `launch-editor`). Not in the shipped app (the bundle is static), but it is the developer machine. | `vite` 7.3.7. Audit now clean; build and tests pass. |
| 3 | Medium | Our own five characters failed the new alignment check (clipped frames, bobbing feet). | Rebuilt through the aligned pipeline (see CHANGELOG). |
| 4 | Medium | Four hand-rolled "click twice to confirm" flows (task row, label, meeting, task editor) that were easy to click through, and links that deleted without asking in one place. | One shared `ConfirmAction` everywhere. |

New open items from pass 2: export/import of a very large database takes tens of seconds and builds the whole file in memory (fine for normal use; a 50k-note user would want a progress message); screen-reader *speech* was not heard (only names, roles and landmarks were checked); dialogs rely on Radix's focus trap and were not re-tested by hand.

## Checked and fine
- **Network:** no listener, no HTTP client in `loaf-core` or `src-tauri`. Local-first holds.
- **Webview:** CSP `default-src 'self'; connect-src ipc:…; img-src 'self' data:`; three capability files, each with only the permissions it uses (events, drag, close, open-url).
- **Links:** only `http`, `https`, `mailto` open (`links.rs`, tested against `javascript:`, `file:`, `data:`).
- **ZIP / pet import:** paths that escape the folder, links and oversized files are refused; only named files are unpacked; `loaf.json` is re-written from checked values.
- **Panics:** 5 `expect`/`unwrap` outside tests (clock fake, a reader-pool permit, app start); none on user input.
- **Icon-only buttons:** all have an accessible name.
- Core is free of Tauri crates (`pnpm check:core-deps`).
