# Sprite packs
Each pack: `pet.json` (only the OpenPets fields), `pluto.json` (our row sources, licence, status), `spritesheet.webp` (standard; a local `spritesheet.png` preview is not committed). Generated, **Unverified** (never loaded by a real pet engine). Layout: 8 columns x 9 rows of 192x208 cells; each `pet.json` marks every row `drawn` or `mirrored` (running-left: right-facing art flipped and re-lit); no row is `derived` any more. Seven packs: bear, bolt, ghosty, mira, mochi, pip, raja. Regenerate: `EXPORT_PACKS=1 pnpm exec vitest run spritePackExport`, then `NODE_PATH=<dir with playwright-core> node scripts/svg-to-png.mjs`. Spec: desktop-pet-docs/docs/character/CHARACTER_STUDIO_SPEC.md.

**Alignment (2026-10-28).** The exporter also writes `strips.svg` (roomy row strips, untracked). `scripts/svg-to-png.mjs` cuts them and runs the skill's `pack.py build`, so our own characters are scaled once, stood on one baseline and centred exactly like a user's. Idle and working rows breathe (a slight stretch about the feet) and running rows rock about their feet: the feet never move. `python3 skills/pluto-character/scripts/pack.py check packs/<id>` must say OK.
