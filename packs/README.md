# Sprite packs
Each pack: `pet.json` (only the OpenPets fields), `loaf.json` (our row sources, licence, status), `spritesheet.webp` (standard; a local `spritesheet.png` preview is not committed). Generated, **Unverified** (never loaded by a real pet engine). Layout: 8 columns x 9 rows of 192x208 cells; each `pet.json` marks every row `drawn` or `mirrored` (running-left: right-facing art flipped and re-lit); no row is `derived` any more. Regenerate: `EXPORT_PACKS=1 pnpm exec vitest run spritePackExport`, then `NODE_PATH=<dir with playwright-core> node scripts/svg-to-png.mjs`. Spec: desktop-pet-docs/docs/character/CHARACTER_STUDIO_SPEC.md.
